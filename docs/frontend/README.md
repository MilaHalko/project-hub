# Frontend docs

The web frontend of Project Hub: a React app served by the API at `/app/`. It is
an addition beyond the spec and has its own plan, separate from the backend
roadmap.

| File | What it holds |
|---|---|
| [`2026-11-14-frontend-design.md`](2026-11-14-frontend-design.md) | Decisions and rejected options: stack, where code lives, auth in the browser, serving and deploy, errors, screens, CI |
| [`roadmap.md`](roadmap.md) | Frontend epics F0–F6, their order, what each screen needs from the API, future improvements |
| [`style.md`](style.md) | The approved look: tokens, type, components, words |
| [`mockups/look.html`](mockups/look.html) | Reference mockup of the look (open in a browser) |
| `specs/` | Design docs of each frontend epic, added as the epics start |

Frontend work follows the project skill `add-frontend-feature`, which reads its
stack, style and layout from this folder.
